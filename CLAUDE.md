# Hushlight — agent conventions

**One app: a contraction timer for the night labor starts.** Extracted from a
private monorepo (decision 0033) and renamed from its working title *Contractions*;
its QA harness and backlog came along. **The source is public under MIT (decision
0067)** — everything committed here is read by strangers. Free forever, no ads, no account —
and radically private: no network capability, no entitlements, no App Group, no
analytics. Everything a user times stays in the app's own sandbox.

Solo project, AI-driven. **You build and decide by default.** Read §"Autonomy" before
you stop to ask anything.

---

## Start here

1. `docs/BACKLOG.md` — what to build next. Find the first `[N]` or `[ ]` in §2. It is a
   ledger, one to three sentences per item with a trail to the record (decision 0065);
   the narrative of a close goes in the BUILDLOG, never back into the backlog line.
2. `docs/BUILDLOG.md` — what happened last session. Newest first: read the top two entries.
   It restarts at the open-sourcing; earlier entries stay in the private repository.
3. `docs/design/DESIGN-SPEC.md` — what "done" looks like visually; §8 owns the gates.
   `docs/design/hushlight/` holds the Nightstand identity research (palette, type,
   voice, screens) that HL-001–003 implemented.
4. `docs/decisions/` — decisions already made. Do not relitigate a numbered entry;
   supersede it with a new one if it turns out wrong. Entries carried from the monorepo
   keep their numbers; new entries continue from the highest number.

## Commands

```bash
./scripts/build.sh             # the app, against the newest installed simulator
./scripts/test.sh [pkg…]       # DesignKit LaborKit LaborSim (all by default)
./scripts/gate.sh              # DESIGN-SPEC §8 acceptance gates, then build
./scripts/labor-sim.sh         # the labor QA harness (decision 0021)
./scripts/labor-mutate.sh      # rubric mutation testing against PatternAnalysis
./scripts/a11y-ax5.sh          # the AX5 accessibility gate (SP-195)
./scripts/shoot-store.sh       # App Store 6.9" screenshot capture
./scripts/shoot-store-duo.sh   # iPhone Duo store shots, one per pose (pose it first)
./scripts/newest-sim.sh        # the newest installed iOS simulator's UDID
```

**CI: the ubuntu gate runs on every pull request and every push to main; the macOS tier is manual-only (decision
0031).** No schedule, no commit-message flag — start it from the Actions tab (or
`gh workflow run CI`) when you need it: before a submission, or for the AX5 gate.
macOS runners bill at the 10x multiplier; starting one is a deliberate act.

**The toolchain is no longer pinned** (decision 0053). The floor is iOS 18.0, so
the scripts use the machine's `xcode-select` — a released app should build on a
released toolchain. That toolchain must be Xcode 27.1 or later: the Duo code names
iOS 27.1 API behind `#available`, and the SDK has to carry it (HL-068). Set `DEVELOPER_DIR` yourself to
aim at a specific one. Bare `swift build` in a package directory targets macOS and
**will** fail on iOS-only API; build through the scripts.

**SP-042a is closed.** App-target UI tests ran locally the moment the Xcode-beta pin
went away — the aborts were a beta-runtime/SDK mismatch, not a machine limitation.
`HushlightUITests` legs, the AX5 gate included, now run here. CI's macOS tier stays
manual (decision 0031) but is no longer the only place they execute.

## Project shape

Generated by **xcodegen** from `project.yml`; `Hushlight.xcodeproj` is gitignored.
Adding a file to the *app target* requires `xcodegen generate`. Files added inside a
package are globbed automatically.

| Package | Owns |
|---|---|
| `DesignKit` | Tokens and components. **The only place fonts and colours are defined.** A pruned fork of the monorepo's — the copies drift deliberately. |
| `LaborKit` | Records, store, pattern analysis, Live Activity attributes, intents. Zero dependencies, on purpose (decision 0018). |
| `LaborSim` | The QA harness engine and its oracle. Tooling only — linked by no app target. `LaborOracle` stays a target, never a product, with no dependencies: a referee sharing code with a player referees nothing. |

## Conventions

- Swift 6 strict concurrency, **iOS 18.0 floor** (decision 0053 — measured, not
  inherited: the only thing above it was one `.scrollEdgeEffectStyle` call, now
  behind an `#available` guard). SPM manifests are `swift-tools-version: 6.0`.
  Anything newer than 18.0 gets an availability guard, never a floor bump; after
  adding an API you are unsure of, run `./scripts/build.sh` and let the compiler
  say.
- **Raw hex, `Color(red:)`, and `Font.system(size:)` are banned in shipped app code
  outside DesignKit.** `scripts/lint-literals.sh` is the single definition of the
  rule; `gate.sh` and CI both call it. Build tooling under `scripts/` is exempt —
  it never enters the app binary (the icon generator draws with CoreGraphics).
  Call sites name a type *role* (`.dataText(.hero)`), never a point size.
- Data numerals are monospaced; prose is SF Pro. Gauges are linear tick tapes —
  **never rings or donuts**, that is an explicit brief guardrail.
- The tint is the ember — warm amber, the Nightstand identity (docs/design/hushlight/,
  decision 0034), defined in DesignKit's `Palette`. Change it through DesignKit tokens
  only, never per-screen.
- Intervals are timed start-to-start, the clinical standard. No figure appears below
  its evidence floor — an em dash, never a zero (decisions 0022–0026 own this).
- Comments explain *why*, not *what*. Match the density of the file you are in.
- **A row printing two or more data figures side by side takes a
  `dynamicTypeSize.isAccessibilitySize` branch and stacks.** At AX5 a `@ScaledMetric`
  fixed column starves the figures beside it and they break *inside themselves* — not
  clipped, every glyph present in the wrong order, which is why Apple's audit reports
  zero on it. Two S2 defects shipped that way (F-0055, F-0056);
  `scripts/lint-row-figures.sh` is the rule, and `gate.sh` and CI both call it.
- No fixed frame heights on text containers. Data values never get truncated.
  Everything must survive XL Dynamic Type — the middle of the night is when
  accessibility settings matter most.

## Who does the work

Christian's call, 2026-08-23. Model roles for agent work in this repo:

| Role | Model | What it does |
|---|---|---|
| Orchestrator | **Opus** | Holds the session, reads the backlog, decides the plan, writes decisions, owns the DoD sign-off. |
| Advisor | **Fable** | Consulted on hard calls before they are made — design direction, copy in the voice, naming, judgement on a fork. Advises; does not land the commit. |
| Executor | **Sonnet** | Implements a scoped item: code, tests, the build/gate loop. |
| Bulk | **Haiku** | Wide mechanical passes — string extraction, residue greps, corpus and fixture chores, file-by-file sweeps. |

The orchestrator stays accountable for anything a delegate returns: a subagent's
report is evidence, not a verdict. The hard gates in §Autonomy do not delegate.

## Autonomy

Default is **decide, log, continue**. Architecture, scope refinements, screens,
copy inside the voice rules — all yours. Write a numbered `docs/decisions/` entry
for anything non-obvious. That entry is the review trail; it is not a request for
permission. If a hard gate blocks an item, park it with a decision-needed entry and
move to the next item rather than waiting.

**Four hard gates need Christian.** These are segregation of duties, not
supervision:

1. **Money** — purchases, paid services, domains, licensing, final price decisions.
2. **Credentials and releases** — Apple ID actions, App Store Connect, external
   TestFlight, and any deploy consuming his API keys or infrastructure.
3. **The privacy ratchet.** No agent may relax these under any rationale:
   - Free forever. No ads, no account, no purchase of any kind.
   - No network capability, no entitlements, no analytics, no third-party code.
   - Nothing a user times ever leaves the device.
   - No fear language, anywhere. The app never shouts; red is not in its palette.
4. **Outside code** (decision 0068). No agent approves, merges or starts a workflow
   run for a pull request opened by anyone but the owner. The `main` ruleset requires
   the code owner's approval, but an agent holding the owner's `gh` login *is* the
   code owner to GitHub, so this line is the only control that tells them apart.

**Public docs (decision 0067).** Nothing personal goes into the repository: no
family or private-life context, no API key IDs, no other teams, businesses or
projects on the account, no internals of the monorepo this came from. Name the owner
as owner. Record a human gate as a fact ("completed on a device"), never as a story.
Secrets live only in GitHub Actions secrets.

## Definition of Done — every item

1. Builds clean; tests green.
2. New logic on authoritative paths — pattern analysis, verdict rules, aggregation,
   the Live Activity contract — has unit tests, and the QA harness still passes.
3. UI work passes DESIGN-SPEC §8: both appearances, XL Dynamic Type, the hex/font
   grep gate, accessibility labels.
4. `BUILDLOG.md` entry appended and `BACKLOG.md` statuses updated **in the same
   commit**.
5. No silent scope changes. Additions enter the backlog first.

Item lifecycle: `[ ]` backlog → `[N]` next → `[~]` in progress → `[R]` self-review →
`[x]` done. You advance items yourself after verifying against the DoD.

## Voice

A steady midwife at 3am: numerate, direct, calm. Evidence first, then the call. No
emoji, no exclamation points, no medical claims or diagnosis language — the app
reports a pattern against the guideline the user chose; their provider's
instructions come first, and the copy says so. Enforced in LaborKit's `Disclaimers`
tests.
