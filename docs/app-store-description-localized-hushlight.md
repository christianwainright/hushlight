# App Store listing — description and promotional text, localized

Backlog HL-049. Third and last of the listing docs: `app-store-listing-hushlight.md`
holds the English and the reasoning, `app-store-listing-localized-hushlight.md` holds
title, subtitle and keywords per storefront, and this holds the two long fields.
**Proposals: the listing needs Christian's approval and App Store Connect is a hard
gate.**

## The closing paragraph is not a translation

Every description below ends with the app's own shipped disclaimer, **verbatim from the
String Catalog** — the same string `Disclaimers.measuredNotDiagnosed` renders on the
Guidance screen and quotes into the review notes. That is deliberate and it is the same
discipline `DisclaimersTests` already enforces for English: the sentence a reader is
told on the store page is the sentence the app tells them, word for word, in their own
language. Re-translating it here would have created a second version of the one
paragraph in this product that must never drift.

## What is *not* localized, and why

Nothing about the structure. The English description's shape — the hook, the two-tap
line, six claims with a heading each, then the disclaimer — is carried into every
language, because the shape is the argument: it opens on what the app does, spends its
middle on the four things no competitor in this category offers, and closes on the
limit of what it can tell you.

Nothing about the register either (decision 0061). No imperative in a claim about the
pattern, no fear language, no medical claim, no naming a competitor. "It won't guess"
survives as a promise about arithmetic, never as reassurance.

## Character budgets

Apple allows 170 for promotional text (editable without review) and 4,000 for the
description. Every field below was measured, not estimated.

| Locale | Promotional | Description |
|---|---|---|
| es | 150/170 | 1938/4000 |
| fr | 169/170 | 2200/4000 |
| de | 155/170 | 1971/4000 |
| it | 167/170 | 2006/4000 |
| pt-BR | 138/170 | 1931/4000 |
| ja | 69/170 | 839/4000 |
| ko | 76/170 | 920/4000 |
| zh-Hans | 50/170 | 625/4000 |

The CJK descriptions are far shorter in characters and about the same in reading time —
a Japanese sentence carries in 40 characters what English needs 90 for. The headroom is
real but was not filled: padding a store description to reach a limit is how a listing
starts sounding like every other listing in the category.
